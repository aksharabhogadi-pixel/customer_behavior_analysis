# Customer Behaviour Analysis

## Project Overview

This project analyzes customer purchasing behaviour using Python, SQL and Power BI.

The objective is to identify patterns in customer demographics, purchasing behaviour, subscription status, shipping preferences, product categories and review ratings.

## Tools & Technologies

- Python
- Pandas
- NumPy
- SQL
- Power BI

## Project Workflow

Raw Customer Data
↓
Data Cleaning using Python
↓
Data Analysis using SQL
↓
Interactive Dashboard using Power BI

## Key Analysis

- Customer demographics
- Revenue by product category
- Customer purchasing behaviour
- Subscription status
- Shipping preferences
- Customer review ratings
- Revenue by age group

## Power BI Dashboard

The dashboard contains:

- KPI cards
- Interactive slicers
- Donut chart
- Pie chart
- Column chart
- Bar chart
- Customer details table

## Files

| File | Description |

## Conclusion

This project demonstrates an end-to-end data analytics workflow using Python, SQL and Power BI to analyze customer behaviour and generate meaningful business insights.
